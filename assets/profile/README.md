# Profile previews

These previews show the linked applications. The profile keeps descriptions and links as real Markdown text.

- Matsu, Tiptap and Avatar PNGs: fresh browser captures of the published demos, September 2026. No generated mockups or replacement UI.
- Matsu is the DaisyUI adaptation credited in [its source repository](https://github.com/HMarzban/daisyui-matsu-theme); its original theme inspiration is credited there.
- Avatar artwork comes from DrawKit, with attribution preserved in [the application repository](https://github.com/HMarzban/notion-avatar-generator).
- Fusegrid GIF and still: unchanged assets from [the game repository](https://github.com/HMarzban/fusegrid/tree/main/media). The GIF uses the actual renderer and movement, with a staged short corridor and shortened fuse for a 3.5-second demonstration. The original capture methodology is recorded in that media README.
- The GIF has a static alternative for visitors requesting reduced motion. The editor screenshots use GitHub-supported light/dark picture sources.
